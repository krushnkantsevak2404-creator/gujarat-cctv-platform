====================================================================
GUJARAT CCTV INTELLIGENCE PLATFORM
TEAM PROJECT SETUP & RUN GUIDE
Gujarat Police Innovation Hackathon 2026
====================================================================

This guide provides step-by-step instructions for teammates to clone,
configure, initialize, and run the Gujarat CCTV Intelligence Platform
on Windows 10/11 laptops.

--------------------------------------------------------------------
1. PROJECT OVERVIEW
--------------------------------------------------------------------
The Gujarat CCTV Intelligence Platform is a centralized surveillance
intelligence application built for the Gujarat Police Innovation
Hackathon 2026 (Model 2: Unified Viewing & Selective Analytics on
Model 1 CCTV Registry & GIS Foundation).

Core Capabilities Implemented (Milestones 1–6):
- CCTV Camera Registry (Live & Recorded sources, metadata, GPS)
- PostGIS Spatial GIS Map (Interactive Leaflet map with custom markers)
- Recorded CCTV Footage Management (Chunked streaming via HTTP 206)
- AI Vehicle Detection (YOLOv8 inference across video frames)
- Multi-Object Vehicle Tracking (ByteTrack temporary Track IDs & trails)
- ANPR & OCR (Automatic Number Plate Recognition & Indian syntax validation)
- Cross-Camera Global License Plate Search

7. BACKEND SETUP (PYTHON VIRTUAL ENVIRONMENT)
--------------------------------------------------------------------
Step 1: Open PowerShell and navigate to the project directory:
cd gujarat-cctv-platform

Step 2: Verify Python version (must be Python 3.10+):
python --version

Step 3: Create a clean virtual environment:
python -m venv .venv

Step 4: Activate the virtual environment:
# On PowerShell:
.\.venv\Scripts\Activate.ps1

# If PowerShell gives an Execution Policy error, run:
# Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
# Then run: .\.venv\Scripts\Activate.ps1

# On Command Prompt (CMD):
.\.venv\Scripts\activate.bat

Step 5: Upgrade pip and install dependencies:
python -m pip install --upgrade pip
pip install -r backend/requirements.txt

--------------------------------------------------------------------
8. FRONTEND SETUP (NODE.JS & REACT)
--------------------------------------------------------------------
Step 1: Open a new terminal / PowerShell window.
Step 2: Navigate to the frontend directory:
cd gujarat-cctv-platform/frontend

Step 3: Install npm packages:
npm install

Step 4: Verify Vite development build:
npm run build

--------------------------------------------------------------------
9. POSTGRESQL SETUP (OPTIONAL - SQLITE FALLBACK ACTIVE)
--------------------------------------------------------------------
The platform supports PostgreSQL + PostGIS out of the box, with an
automatic SQLite fallback (storage/local_dev.db) if PostgreSQL is not running.

If setting up PostgreSQL:
1. Open pgAdmin 4 or psql command line.
2. Create the platform database:
   CREATE DATABASE gujarat_cctv_db;

3. Connect to the database:
   \c gujarat_cctv_db

--------------------------------------------------------------------
10. POSTGIS SETUP
--------------------------------------------------------------------
Run the following SQL commands in PostgreSQL pgAdmin query tool:

CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS postgis_topology;

Verify PostGIS is active:
SELECT postgis_full_version();

11. ENVIRONMENT VARIABLES SETUP
--------------------------------------------------------------------
Step 1: Copy the .env.example template to .env in the project root:
# On PowerShell:
Copy-Item .env.example .env

# On CMD:
copy .env.example .env

POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_actual_postgres_password
POSTGRES_DB=gujarat_cctv_db
POSTGRES_SERVER=localhost
POSTGRES_PORT=5432

CRITICAL RULE:
Never commit your '.env' file or database passwords to GitHub!

--------------------------------------------------------------------
12. DATABASE INITIALIZATION
--------------------------------------------------------------------
Database tables and migrations are initialized AUTOMATICALLY by SQLAlchemy
when the FastAPI backend starts up:
- Base.metadata.create_all(bind=engine) creates all tables:
  * cameras (CCTV Registry with GeoAlchemy2 spatial point geometry)
  * camera_footage (Recorded video clips & metadata)
  * vehicle_detections (Frame-by-frame YOLO detections with Track IDs)
  * vehicle_tracks (ByteTrack track summaries & representative crops)
  * anpr_detections (Localized plate bboxes, OCR strings, Indian formats)
  * processing_jobs (Async inference jobs & progress counters)
- Sample Gujarat Police CCTV camera assets are automatically seeded if
  the camera registry is empty!

No manual migration commands or Alembic setup needed for first run.

--------------------------------------------------------------------
13. AI MODEL SETUP (YOLOv8 + EASYOCR)
--------------------------------------------------------------------
The AI models are downloaded and cached automatically upon first run:

1. YOLOv8 Vehicle Detection & Tracking:
   - Model: YOLOv8 Nano (yolov8n.pt, ~6.5 MB)
   - Target Classes: car, motorcycle, bus, truck (COCO classes 2, 3, 5, 7)
   - Tracker: ByteTrack (bytetrack.yaml)
   - Auto-saved in: ai/yolov8n.pt or backend/yolov8n.pt

2. EasyOCR Plate Recognition:
   - Models: CRAFT Text Detector & CRNN Character Recognizer (~80 MB)
   - Language: English alphanumeric ('en')
   - Auto-downloaded by EasyOCR to ~/.EasyOCR/model/ on first run.

- CPU Support: 100% operational on standard CPU without dedicated GPU.
- GPU Support: Automatically utilized if NVIDIA CUDA is detected.

19. COMMON ERRORS & TROUBLESHOOTING
--------------------------------------------------------------------
Q1: "Python is not recognized as an internal or external command"
Solution: Add Python to Windows PATH or reinstall Python with "Add python.exe to PATH" checked.

Q2: "Execution of scripts is disabled on this system" in PowerShell
Solution: Run in PowerShell as Administrator:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Q3: "Connection refused (127.0.0.1:5432)" on backend startup
Solution: If PostgreSQL is not running, the application will automatically
fall back to SQLite (storage/local_dev.db). If you want PostgreSQL, ensure the
PostgreSQL Windows service is started from Windows Services (services.msc).

Q4: "Port 8000 or 5173 is already in use"
Solution: Find and terminate the previous process or specify another port:
uvicorn app.main:app --host 127.0.0.1 --port 8001

Q5: "ModuleNotFoundError: No module named 'lap'"
Solution: Run 'pip install lap' inside your activated virtual environment.

Q6: "EasyOCR model download is slow"
Solution: On first run, EasyOCR downloads ~80MB CRAFT & CRNN weights from
GitHub releases. Ensure active internet connectivity for the initial run.
